File Cabinet

Allows you to view and store mail in your File Cabinet either online or offline. Your File Cabinet does not synchronize with your Personal Filing Cabinet (PFC) on your desktop AOL application; the two are separate storage areas. However, all data in the File Cabinet is backed up to your desktop computer during a HotSync.

Tap the File Cabinet icon on the AOL main screen to open your File Cabinet. The tab displayed will be the last tab you accessed. If you have not yet accessed the File Cabinet, the Saved tab will display.

The File Cabinet has all the menu options of the Online Mailbox, with two exceptions: The Refresh List and Mark All Mail as New commands are found only in the Online Mailbox.

Saved tab

The Saved Tab lists messages you have read and then saved under one of the following conditions.

  • You read a message, and then tapped the Save button at the bottom of the message on the Online Mailbox screen.
  • Before reading the message, you chose that all messages be automatically saved by checking the "Save a copy of all mail I read" box on the Preferences screen.
  • Before reading the message, you checked the Put unread mail into "Saved" on the Auto AOL screen.

Sent tab

The Sent tab lists messages you have sent from this handheld device, provided you previously checked the "Save a copy of all mail I send" box on the Preferences screen. Checking this box automatically places all sent messages in the Sent tab.

Waiting tab

The Waiting tab of your File Cabinet is a repository for any message you write, forward or reply to, and then store by tapping Send Later.

The Waiting tab lists composed messages, replies and forwards you have designated to be sent at a later time by tapping Send Later. When you run Auto AOL, all Waiting messages will be sent automatically if you checked Send "Waiting" mail on the Auto AOL screen.

Read Button

Tap Read at the bottom of the screen to open the highlighted message. (Refer to the Reading Mail section for details).

Delete Button

You can delete a message in any tab of your Online Mailbox by tapping Delete at the bottom of the screen. If the "Confirm before delete" box under Preferences of the Options menu is checked, a confirmation window displays.

If you tap Yes to delete the message, it is removed and cannot be recovered.

Write Button

Tap Write at the bottom of the screen to display a blank Write Mail screen. The sending choices depend on whether you are offline or online. If you are offline, you can place the message in the Waiting tab. If you are online, you can send the message immediately. (Refer to the Writing e-mail section for details).

Reply Button

You can reply to any message you read in any tab of your Online Mailbox or from the Saved tab in your File Cabinet. In your response, you can quote part or all of the original message to remind the recipient(s) of the context of the original message. (Refer to the Read Mail section for more details).

Fwd Button

You can forward any message you read in any tab of your Online Mailbox or from the Saved tab in your File Cabinet. As with your desktop AOL application, the original message will be appended to the message body. You can quote specific text from the original message to comment on by highlighting the text before you tap Fwd. (Refer to the Read Mail section for more details).

Send Button

Available only from the Waiting tab, the Send button sends messages that have been placed in the tab if you are online. Highlight the message and tap Send. If you are offline, the Send button is not displayed.

Edit Button

Available only from the Waiting tab, you can edit the content of a message, online or offline, before sending it. In addition, because there is no Read command in the Waiting tab, you can also use the Edit command to simply review a message without changing it.

  1. Highlight an e-mail message and tap Edit. The Edit Mail screen displays showing the message as it was originally saved in the Waiting tab.
  2. Change any aspect of the message.
  3. Tap Save to put the altered message in the Waiting tab.
  4. Tap Cancel if you don’t want to save the changes.
