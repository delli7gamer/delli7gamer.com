Writing E-Mail

You can write a new e-mail message by tapping the Write icon on the main AOL screen, or the Write button on any of the tabs in your Online Mailbox or File Cabinet. This displays a blank Write Mail screen that lets you write, then send or store an e-mail message. Use the on-screen keyboard or the Graffiti writing area to enter or edit text and/or numbers. In addition, the Edit menu contains several functions to facilitate message writing.

Writing a new message

  1. To: Tap directly on (the To: button) to display and enter an e-mail address from your Address Book, or tap in the To: field to enter an address manually. Press the down arrow to expand the field, if necessary. You can enter up to 4,000 characters of text in the To: field.
  2. CC: Repeat step 1 in the CC: field if you want to send a copy to other recipients. You can enter up to 4,000 characters of text in the CC: field.

    - To enter multiple addresses in the To: or CC: fields, separate the addresses with commas.

    - To send a blind copy, enclose the address in parentheses in CC: field. The recipient of the blind copy will receive the message with his or her address shown in a BCC: field. The address of the recipient of the blind copy will not be known to any of the other recipients. To send multiple blind copies, separate the addresses with commas and surround them in parentheses, i.e., (abc, def, ghi).

  3. Subj: If desired, enter a subject. You can enter up to 255 characters in the Subj: field.
  4. Tap to place the cursor in the message field and enter the message. If the message extends beyond the screen limit, additional lines and a scroll bar appear. You can enter up to 32K of text in the body of the message.
  5. When the message is complete, choose one of the following command buttons:
    • Send Now: Tap to send the message immediately. An information window appears telling you that your mail has been sent. (This button is not available offline.)
    • Send Later: Tap to put the message in the Waiting tab of your File Cabinet. An information window appears telling you that the message has been saved in the Waiting tab of your File Cabinet.
    • Cancel: Tap to close the screen. You will see a confirmation window telling you that you are about to lose the data you have entered. Tap Yes to cancel, or No to return to the message.

    Tap the down arrow to expand the corresponding field to enter more text. In the following example, the text "This subject is too long to fit on one line" was entered in the Subj: field. This causes a "+" to appear next to the arrow, indicating that additional text, not displayed on the screen, is in the expanded field.

    Tap the down arrow in the expanded field to display the complete text entered in the field, as shown in the following screen.

    Tap the up arrow in the upper right corner of the expanded field to close the expanded field.

Edit Menu

With the Write Mail screen open, tap the Menu icon ( ), then tap Edit to display the Edit menu.

Undo Undoes a Cut, Copy or Paste command from this menu. It does not remove text you have entered in the message.
Cut Cuts selected text and places it on the clipboard.
Copy Copies selected text and places it on the clipboard.
Paste Pastes text from the clipboard into the message at the insertion point.
Select All Selects the entire content of whatever field the cursor is in. You can then cut or copy the selected text to the clipboard.
Keyboard Opens the on-screen keyboard to enter text in the message.
Graffiti Help Displays the entire Graffiti alphabet, including numbers, punctuation and special characters.

Options Menu

With the Write Mail screen open, tap the Menu icon (), then tap Options to display the Options menu.

  • Preferences: Allows you to set or change the following Preferences in AOL on your handheld:
    • File Cabinet preferences.
    • Confirm before deleting an e-mail message or ending an IM session.
    • Notification of instant message sounds.
    • Sorting display options in your File Cabinet and Online Mailbox.
  • About AOL: Displays information about the AOL application on your handheld and how to obtain technical support.

Signature Menu

With the Write Mail screen open, tap the Menu icon (), then tap Signature to display the Signature menu.

  • Setup: Enter the text you want to use as your signature on e-mails you send and, if desired, check the Always Insert Signature box.
  • Insert: Tap to place your "signature" created via Setup at the end of the e-mail.

Using your Palm Address Book in writing and forwarding mail

You can use your Palm Address Book to simplify entering screen names and Internet addresses in messages you write or forward. The address must be listed as an e-mail address in your Palm Address Book. Consult the Palm documentation for information on placing an e-mail address in the Address Book.

  1. On the AOL Write Mail screen, tap directly on (the To: button) or CC: button to display the e-mail addresses in your Palm Address Book.
  2. Highlight an address and tap Add.
  3. The address is added to the To: or CC: or field that you tapped on the Write Mail screen.

Note: You can use the Look Up field in your Address Book to find and highlight an entry if you have a long list of entries. Entering the first letter, or the first few letters of the name (not the e-mail address) highlights the desired entry.

Replying to and forwarding mail

You can reply to, or forward any message you read in any tab of your Online Mailbox or from the Saved tab in your File Cabinet. In your response, you can quote part or all of the original message to remind the recipient(s) of the context of the original message.

Deleting mail

You can delete a message in any tab of your Online Mailbox by tapping Delete at the bottom of the screen. If the "Confirm before deleting mail" box under Preferences of the Options menu is checked, a confirmation window displays.

If you tap Yes to delete the message, it is removed and cannot be recovered.
