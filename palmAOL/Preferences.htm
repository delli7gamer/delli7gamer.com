Preferences

You can set or change the following Preferences from almost any screen in AOL on your handheld at any time. Tap the Menu icon  (  ), then tap Preferences from the Options Menu


File Cabinet

  • Save a copy of all mail I read: Check this box to automatically place a copy of all mail you have read in the Saved tab of your File Cabinet.

  • Save a copy of all mail I send: Check this box to automatically place a copy of all mail you send from AOL on your handheld device in the Sent tab of your File Cabinet.

    Note: Saving mail to your File Cabinet will, of course, draw on the limited memory of your handheld.

Confirmations

  • Confirm before delete: Check this box to automatically display a confirmation message every time you delete an e-mail message, end an IM session, delete a buddy or group from your Buddy List, etc.

Sounds

  • Enable Instant Message Sounds: Check this box to automatically play a predefined sound when your buddies sign on or off and when you send or receive messages.

Sort by

  • Date: Tap Date to sort and display e-mails in date order in your File Cabinet and Online Mailbox.
  • Sender: Tap Sender to automatically sort and display e-mails in alphabetical order by the name of the sender in your File Cabinet and Online Mailbox.
  • Subject: Tap Subject to sort and display e-mails in alphabetical order by the Subject field in your File Cabinet and Online Mailbox.

Tap Done to return to the previous screen.

Privacy Preferences

You can set or change the following Privacy Preferences only from the Buddy List screen or the Inst Msg screen. Just tap the Menu icon (), then tap Privacy Preferences from the Options Menu

Choose only one of the following:

  • Allow all users to contact me: Select this option to allow all users to see you in their Buddy List windows and send you messages.
  • Allow only users on my Buddy List: Select this option to allow only users on your Buddy List to see you in their Buddy List windows and send you messages.
  • Block all users: Select this option to prevent all users from seeing you in their Buddy List windows and sending you messages.
  • Allow only the users listed below: Select this option to allow only users you specify to see you in their Buddy List windows and send you messages.



    When you tap this option, the list box below becomes active and both an Add and Delete button are displayed. Tap Add and enter the screen name of the buddy you want to include on this list on the Enter Name screen, then tap OK. To delete a buddy from this list box, highlight it and tap Delete; a confirmation screen will display.

  • Block the users listed below: Select this option to prevent the users you specify from seeing you in their Buddy List windows and from sending you messages.

    When you tap this option, the list box below becomes active and both an Add and Delete button are displayed. Tap Add and enter the screen name of the buddy you want to include on this list on the Enter Name screen, then tap OK. To delete a buddy from this list box, highlight it and tap Delete.
Tap Done to return to the previous screen.
