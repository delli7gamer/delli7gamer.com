Additional Setup Location Options

The Setup Locations option allows you to add, edit, delete phone numbers and locations (groupings of one or more phone numbers to access AOL.) The location contains general dialing options and the phone number(s) within the location contains more specific dialing options.

Before you begin your first AOL session on your handheld, you should define a location. Other locations with additional access numbers can be added later. Unless you already know your access number, your first AOL session on your handheld must take place in the United States or Canada to dial the toll free number and download the access number list onto your handheld. In subsequent sessions, the access number list will then be on the handheld and you can access AOL on your device from any country.

  1. Tap Setup on the Sign On screen to display the Setup Locations screen.



  2. Tap Add to display the Add... screen.
    • Edit: If you highlight a location, displays the Location screen. If you highlight a phone number, displays the Access Number screen.
    • Delete: Deletes the highlighted location or access number. A confirmation message will display.
  3. Tap Next.

Add...Screen

This screen allows you to add a new location (such as Home or Work) or add an access number to a location.

  1. You can choose only one of the following options:

    • Add a new dial up location: Displays the Location screen.
    • Add a new Access Number to: If you have more than one location already set up, tap the down arrow to select the location to which you want to add an access number. The Add Number... Screen displays.
  2. Tap Next.

Add Number...Screen

  1. You can choose only one of the following options:

    • Search for AOL Access numbers: Displays the Select Country screen.
    • Add custom number.
  2. Tap Next.

Add Custom Number

If you already know your access number, select Add custom number on the Add Number... screen, then tap Next to display the Access Number screen:

  1. Phone Name: Enter the name of this location, such as Primary, or a city name, such as Irvine.
  2. Access Number: Enter the phone number.
  3. Use Prefix: If a prefix is required, check the box and enter the number, such as 1-949.
  4. Network: Enter the network to which the phone number is assigned, such as AOLnet.
  5. Tap Done.
  6. The Setup Locations screen will display with the new access number phone name highlighted in the list and Number, exactly as dialed displayed at the bottom of the screen. If the number is not correct, tap Edit to make corrections, then return to this screen.
  7. Tap the left arrow ( ) to return to the Sign On screen.

Changing Dialing Order

The Setup Locations screen displays the phone numbers selected during setup for the corresponding location name. The access numbers are dialed sequentially according to their position in the list. You can change the sequence in which the numbers are dialed by dragging a phone number to a new position in the list.
